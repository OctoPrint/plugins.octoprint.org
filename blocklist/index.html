Starting with version 1.3.6 OctoPrint now supports the use of a centralized plugin blocklist, to prevent loading of specific plugin versions that are known to cause serious issues with specific OctoPrint versions that interfere severly with normal operation.

If configured as such, OctoPrint will not load any plugins that are listed on this blocklist and match the provided versions. Deinstallation or manual upgrade of such plugins will however still be possible.
